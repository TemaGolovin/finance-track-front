## Открытые баги и продукт

| Приоритет | Задача                                     | Примечание                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| --------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Средний   | **Юридические документы на английском**    | Политика конфиденциальности и пользовательское соглашение есть только на русском (`privacy-ru-content`, `terms-ru-content`) и открываются на `/privacy` и `/terms` при любой локали. Нужны английские тексты и показ версии по текущему языку.                                                                                                                                                                                                                                                                                                              |
| Средний   | **Статистика группы по участникам**        | `GET /user-group/:id/stat` отдаёт сумму по групповым категориям за период и тип (доход или расход) сразу по всем, чьи категории сопоставлены. Разреза по человеку нет: нельзя посмотреть траты и доходы одного участника, только общую диаграмму. Нужен фильтр: вся группа, только я, конкретный участник — и для расходов, и для доходов. Операции уже хранят `userId`. Как показать разрез (фильтр поверх текущей диаграммы, доли участников или оба варианта) — продумать; список операций и диаграмма при одном и том же фильтре не должны расходиться. |
| Средний   | **Подсказка при создании личной категории** | Если у пользователя есть группы, в форме создания личной категории (`category-form`) показать информационную плашку: траты и доходы по этой категории попадут в группу только после сопоставления с групповой категорией; групповые категории создаёт только создатель группы. Плашку не показывать, если групп нет. |
| Средний   | **Подсказка о несопоставленных категориях в группе** | На экране группы (`group-detail`) показать информационный блок, если есть несопоставленные категории: личные категории пользователя без связи с групповой или групповые категории без связи с личной. В тексте пояснить, что траты и доходы по несопоставленной категории в группу не попадают, и вести на вкладку сопоставления. Блок скрывать, когда все категории сопоставлены. |
| Средний   | **Калькулятор в сумме операции** | В форме операции (`operation-form`) рядом с полем суммы нужен калькулятор: посчитать выражение прямо в приложении и сразу подставить результат в сумму. Сейчас сумма вводится только вручную. |
| Средний   | **Удаление группы и выход из группы** | На экране группы (`group-detail`) нет явных действий: создатель не может удалить группу, участник — выйти. Бэкенд: `DELETE /user-group/:id` уже есть (только создатель). Выход: `removeFromGroup` в сервисе есть, HTTP-эндпоинта нет (кик — `DELETE /user-group/:groupId/members/:memberId`, только создатель, себя убрать нельзя). Нужны кнопки с подтверждением: удалить группу (создатель) и «Выйти из группы» (участник, не создатель). После успеха — список групп. Когда удаление и выход будут готовы: `feature/group-row-actions` на `GroupCard` (как `operation-row-actions`) — у создателя «Редактировать» и «Удалить», у участника только «Выйти». |
| Низкий    | **Стартовое имя категории «Продукты»**     | Новому аккаунту создаётся категория с ключом `supermarket` и подписью «Супермаркеты» / «Supermarkets». Для новых регистраций заменить подпись на «Продукты» / «Groceries» в `defaultCategories`. Уже созданные категории не переименовывать: имя хранится в записи пользователя и меняется вручную.                                                                                                                                                                                                                                                         |
| Средний   | **Предупреждение при смене дефолтной категории** | Влияет на сопоставление групповых категорий с личными: пользователь должен явно понимать последствия перед сменой дефолтной категории. |
| Средний   | **Форма обратной связи** | Форма, где можно описать проблему или предложение по развитию сервиса. Почта, на которую ответить, обязательна: без неё отправка недоступна. |

### Критерий «можно открывать шире бету»

- Закрыт блок **критично перед тестовым деплоем**.
- Если в тесте семьи — закрыт блок **семейные группы**.
- Бэкапы крутятся по расписанию, есть способ узнать, что API/БД легли.
- SMTP настроен или сознательно не используется.
- Юр. тексты вынесены; перед широким запуском — прод-URL/реквизиты в `legal-public-meta.ts`.

## Приоритетный бэклог (крупные темы)

### 1. Фильтрация статистики и операций: стор или рефакторинг URL

**Что:** Один источник правды для периода, типа, категории; список операций и статистика не разъезжаются.

**Сейчас:** `src/feature/operation-filters/model/use-transactions-filters.ts` и `src/feature/group-selector/model/use-group-selector.ts` — URL (`type`, `period`, `startDate`, `endDate`, `categoryId`, `groupId`).

**Стор (Zustand и т.п.), если нужно:** синхронизация вкладок без URL; меньше `router.push` и гонок с `useEffect`; состояние вне одного route.

**Альтернатива:** единый разбор `URLSearchParams`, URL остаётся source of truth.

**Критерий:** нет дублирования список/статистика; шаринг ссылки сохраняет фильтры. Сложность: S–M.

### 2. Другие способы авторизации

Сейчас: email + пароль, JWT, refresh по `deviceId`.

Направления: OAuth2 (Google / Apple / GitHub), magic link, Passkeys / WebAuthn. Самописный `auth` vs Clerk/Auth0/Supabase.

Транзакционная почта уже есть — примитивы для magic link готовы, продуктово это отдельно. Сложность: M–L.

### 3. PWA и Web Push

Базовый профиль готов. Дальше напоминания («время внести расходы»).

| Часть          | Содержание                                                                |
| -------------- | ------------------------------------------------------------------------- |
| **PWA**        | `manifest` уже есть; нужен service worker, офлайн/кэш по необходимости.   |
| **Web Push**   | разрешение, subscription на бэкенде, VAPID, эндпоинты подписки.           |
| **Расписание** | cron/worker на сервере; клиентский таймер при закрытой вкладке ненадёжен. |
| **UI**         | время и вкл/выкл в профиле.                                               |

Сложность: M–L.

## Идеи развития

| Направление                                             | Зачем                                                                                                        |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Роли в группе** (владелец / редактор / только чтение) | В схеме нет `role` / `permission`. Для «только семья» терпимо; для чужих в одной группе — почти обязательно. |
| **Краткосрочная группа / «событие»**                    | Отдельный тип группы для поездок, вечеринок, мероприятий: общие траты, кто что оплатил, в конце — расчёт «кто кому сколько должен» (упрощённые переводы между участниками). Не семейный бюджет на годы, а закрываемый цикл. Уровень идеи. |
| **Повторяющиеся операции**                              | Подписки, аренда.                                                                                            |
| **Бюджеты / лимиты по категории**                       | После статистики.                                                                                            |
| **Импорт трат из файла** (Excel, PDF, выгрузка банка и др.) | Перенос операций из внешних источников с сопоставлением с текущими категориями и группами пользователя. Уровень идеи: формат, парсинг и маппинг ещё не продуманы. |
| **Напоминания о записи трат**                           | Уведомления с настраиваемым временем; по умолчанию выключены. См. также блок «PWA и Web Push» в приоритетном бэклоге. |
| **Реакции и комментарии к операциям**                   | Реакции на траты других участников группы или комментарии к операциям; при событиях — уведомления.           |
| **Несколько валют + курс**                              | Если не только RUB.                                                                                          |
| **Полнотекстовый поиск**                                | Комментарии и суммы, когда операций много.                                                                   |
| **Email-дайджесты**                                     | Отдельно от push.                                                                                            |
| **2FA**                                                 | При усилении безопасности.                                                                                   |
